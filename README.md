 # 🚀 Profile & Product Search App

Welcome to the Profile & Product Search App — a modern iOS application built with clean architecture and real-world UX in mind.

This app allows users to view rich profile information, explore products, read reviews, and navigate ads and tags — all within a seamless and responsive UI.

---

## 🚀 What’s Inside?

### 🔥 Core Features

- **User Profiles**
  - Beautifully displays user images, names, and profile details.

- **Profile Navigation**
  - Easily switch between `Products`, `Reviews`, and `Followers` tabs.

- **Product Exploration**
  - View product images, names, prices, countdown timers, and exclusive offers.

- **Smart Search**
  - Quickly find products through keyword-based search filtering.

- **Interactive Lists**
  - Scroll through ads horizontally.
  - Choose from dynamic, filterable tags.

- **Seamless Navigation**
  - Integrated `UITabBarController` with five main screens for smooth flow.

---

## 🧱 Built With

- **UIKit** — Classic, flexible UI development.
- **MVVM Architecture** — Protocol-oriented, clean, and scalable.
- **RxSwift + RxCocoa** — Reactive programming done right.
- **Offline Caching** — File-based generic storage layer.
- **State Management** — Elegant handling of loading, success, and error states.
- **SOLID Principles** — Clean, maintainable, extendable codebase.
